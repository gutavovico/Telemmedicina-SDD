# Interpretación por texto de reportes CU22 en web

La pantalla Angular `/analitica` permitirá escribir una solicitud y usar `POST /analytics/reportes/interpretar`. Enviar/Enter aplicará una definición válida completa y consultará; Aplicar filtros solo actualizará controles. La autorización ADMIN y el ámbito de clínica siguen en el backend.

No incluye voz, eMail, persistencia de reportes, cambios de base de datos ni modificaciones de web ajenas a Analytics.
