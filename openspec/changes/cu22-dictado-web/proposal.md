# Dictado web de solicitudes CU22

El sistema permite al ADMIN dictar una solicitud breve en la barra de reportes. El backend transcribe audio. De forma predeterminada, la persona revisa el texto antes de usar Enviar o Aplicar filtros. La opción web «Enviar al terminar» permite interpretar y generar tras una detención explícita, reutilizando el mismo flujo de Enviar y sus validaciones. Se reutilizan Groq, autorización y la interpretación vigente.

Fuera de alcance: dictado móvil, generación por fin de tiempo o error de grabación, nuevas tablas, cambios CU05, Neon, eMail y permisos CU27 ajenos a reportes.
